# پروژه تحلیل داده‌های الماس

## معرفی پروژه
در این پروژه، مجموعه داده Diamonds با استفاده از زبان برنامه‌نویسی Python بررسی و تحلیل شده است.

هدف پروژه، آشنایی با داده‌ها، پاک‌سازی اطلاعات و بررسی ارتباط بین ویژگی‌های الماس و قیمت آن است.

## ابزارها و کتابخانه‌ها
- Python
- Pandas
- NumPy
- Seaborn
- Matplotlib
- Jupyter Notebook

## مراحل انجام پروژه
1. بارگذاری مجموعه داده Diamonds
2. بررسی ساختار و اطلاعات ستون‌ها
3. بررسی فراوانی و درصد ویژگی‌های دسته‌بندی‌شده
4. شناسایی مقادیر گمشده
5. شناسایی و حذف ردیف‌های تکراری
6. بررسی و حذف ردیف‌های دارای ابعاد صفر
7. تحلیل رابطه وزن و قیمت
8. رسم نمودارهای تحلیلی
9. بررسی همبستگی بین ویژگی‌ها

## نتیجه تحلیل
بررسی‌ها نشان داد وزن الماس ارتباط مثبت و قوی با قیمت آن دارد. همچنین توزیع قیمت‌ها چولگی به راست دارد.

## فایل‌های پروژه
- `diamonds_analysis.ipynb`: فایل اصلی تحلیل داده‌ها
- `requirements.txt`: فهرست کتابخانه‌های موردنیاز پروژه
- `README.md`: معرفی و توضیحات پروژه
